YUCL · 用户手册

人物·背景成片 · 本地免费运行 · Java/Spring Boot（端口 8791）

一、快速开始（3 步出一支片）

1
给素材：在「人物图片」「背景图片」里添加卡片——每张可以上传图片，或写提示词让 AI 生成图片。
2
排镜头：每个镜头 = 1–2 个人物 + 1 个背景 + 一句台词/动作 + 秒数。引擎选「本地合成」（免费离线）或「AI 生成」（需 AI 视频模型，图片须为生成来的公开链接）。
3
点 生成人物·背景视频。任务立即开始，在右下「近期作品」里看进度条，可以取消或失败后重试。完成后直接在播放区预览。
想省事：用左栏「一键剧本」输入主题（如"60 秒校园能量饮料宣传片"），LLM 自动写好标题/人物/台词/分镜，点「填入下方表单」，然后给人物和背景生成图片即可。

二、人物·背景 表单

控件说明
画幅竖屏 9:16（默认，短视频）/ 横屏 16:9 / 方形 1:1
导出分辨率1080P（默认）/ 720P（更小更快，适合网络传播）
视频模型 / 生图模型ai 引擎镜头用什么视频模型；提示词卡用什么生图模型（来自「模型配置」）
人物大小人物占画面高度比例，0.4–0.9，越大越近
单人站位左下/中下/右下/居中；两人同框时自动左右分置
烧录字幕把每句台词烧进画面（可关）。字幕大小：小/中/大
旁白配音为台词配音。全局「旁白声源」+ 每个人物卡可单独设音源（默认/系统音色/我的语音文件）

三、旁白声源 与 BGM

「旁白声源」卡：系统音色（edge-tts，本机网络不可用时会自动降级）或我的语音文件（上传到语音库，选一个当默认旁白，可试听）。

「BGM 背景音乐」卡：上传背景音乐到 BGM 库（mp3/wav/m4a/aac/flac/ogg，≤50MB），选一首并拖音量（默认 18%）。生成时会铺在旁白下面，不会盖过人声。

人物卡上的音源优先级：人物自己的语音文件 > 全局默认 > 系统音色。某句台词没有任何音频源时，任务完成提示里会有声源告警（该镜无声音）。

四、一键剧本（LLM 写故事）

输入故事主题 → 选风格（产品推介/故事短剧/知识科普/生活Vlog）和镜数 → 点「生成剧本」。剧本会给出：

  • 标题 + 一句话卖点
  • 人物：名字、外观描述（可直接当生图提示词）、建议音色
  • 分镜：每镜的人物/背景/画面/台词/时长（4–12 秒）

「填入下方表单」会自动建好人物卡、背景卡和镜头列表；「复制剧本」可拿纯文本去别处用。填入后仍需给每张人物/背景卡生成图片（或上传）才能出片。

五、模型配置（各家供应商）

「模型配置」里可以添加任意 OpenAI 兼容的 AI 供应商，每家填：名称 / Base URL / API Key / 生图模型 / 视频模型 / 文本模型（逗号分隔多个，默认项写在前面）。勾「使用此供应商」即切换；测试连接会拉取该家的模型列表，方便你核对。

能力要求
生图模型任何 OpenAI 兼容服务（/images/generations）都能用
视频模型仅支持视频协议的模型网关（提交+轮询）。其他家的视频镜头请选「本地合成」引擎
文本模型任何 OpenAI 兼容 /chat/completions，用于一键剧本
API Key 只保存在本机文件（YUCL 数据目录下的 provider-config.json），不会上传任何地方。

六、任务管理（进度 / 取消 / 重试）

点「生成」后任务立即编号并进入渲染队列（同一时间渲染 1 个，多余排队）。「近期作品」卡片实时显示进度条和当前步骤（镜头 i/N · 本地合成 → 合并 → BGM → 字幕）：

  • 取消任务：立即停止（正在跑的 ffmpeg 会被杀干净，无残留），标记为「已取消」
  • 重试：失败/取消的任务一键重跑（用当时的全部参数）
  • 删除作品：卡片右上角 ×（确认后会连磁盘文件一起删）

七、数据备份 与 维护

左栏「维护」区：

  • 下载备份：把 图片库/语音库/BGM库/任务历史/模型配置/运行日志 打包成一个 zip（放在桌面即可，随备份随时存 U 盘）。
  • 恢复备份：选一个备份 zip，内容原样写回本机（只认备份包里的已知结构，不会误伤其他文件）。
  • 查看日志：显示最近 200 行运行日志，可复制排错。
数据位置
图片 / 语音 / BGM 库本机 YUCL 媒体目录（开发机为 D:\ai-video-java\{images, voices, music}，其他电脑自动落在 C:\Users\你的用户名\YUCL\media\）
生成的视频（运行目录）YUCL 缓存目录下的 ui\（同上规则）
任务历史 + 模型配置YUCL 数据目录（YUCL\data\ 或开发机旧位置）

八、常见问题

任务失败，提示 ffmpeg 相关？

程序自带 ffmpeg（YUCL 目录里的 ffmpeg\ 文件夹，请保留它；healthz 接口能看到当前实际用的 ffmpeg 路径）。报错里会带 ffmpeg 输出的最后几行，可粘到「查看日志」对照。

AI 生成镜头卡在"等待"？

系统内置模型免费额度高峰期会返回 503 video_queue_full——是对方容量满，不是程序坏了。会自动排队重试（默认 4 次，每次等待更久）；还是不行就等会儿再点「重试」，或把该镜引擎改成「本地合成」。

上传的图片/语音 50MB 报错？

单个文件上限 50MB。长语音可以只保留需要的段落。

换电脑/重装后数据丢了？

用「下载备份」提前存好，到新机器装好后在「维护」里「恢复备份」，图片库、语音库、BGM、任务历史、模型配置一次全回来。

启动时提示端口被占用？

YUCL 默认用本机 8791 端口。如果别的程序占用了它，启动会给出中文提示（而不是直接闪退）：关掉那个程序再启动，或设置环境变量 SERVER_PORT=8792 后启动（快捷方式可加参数/改环境变量）。

双击 .exe 启动？

YUCL.exe 自带 Java 运行时和 ffmpeg，整份 YUCL 文件夹拷到别的 Windows 电脑（任意盘符、无需安装）双击即可运行；首次启动稍慢。数据自动存到该电脑的 C:\Users\你的用户名\YUCL\。开发机也可以继续用 启动AI短视频Java.bat（需 JDK17+Maven）。

YUCL 窗口（应用界面）？

双击 YUCL.exe / 桌面快捷方式时，YUCL 现在打开一个独立的应用窗口（不是浏览器）：窗口里就是完整界面，关闭窗口 = 退出 YUCL（服务随之停止）。窗口大小和位置会被记住，下次打开保持不变；任务栏/标题栏都是 YUCL 图标。重复双击只会再开一个窗口，服务只有一个（不会重复启动）。想回到"浏览器打开"的旧方式：设置环境变量 YUCL_GUI=0 再启动。

用安装程序安装 / 卸载？

运行 YUCL-Setup.exe（YUCL-Setup 文件夹里，可先解压 zip）：提示时输入安装目录（直接回车默认装到 C:\Users\你的用户名\AppData\Local\YUCL，也可装到 D 盘等任意位置；普通用户目录无需管理员权限），安装完自动生成桌面「YUCL」快捷方式。卸载：运行安装目录里的 YUCL-Uninstall\YUCL-Uninstall.exe，或「设置 → 应用 → YUCL → 卸载」；卸载时会询问是否同时删除用户数据（默认保留，可用「恢复备份」找回）。

有问题先看「维护 → 查看日志」最后 30 行，把内容发给维护者，基本都能定位。
